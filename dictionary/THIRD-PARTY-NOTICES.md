# Third-party dictionary data

This application bundles `ecdict.csv` from [ECDICT](https://github.com/skywind3000/ECDICT), an English-to-Chinese dictionary database by Linwei and contributors.

- Source: `https://github.com/skywind3000/ECDICT`
- Data file: `ecdict.csv`
- License: MIT
- Local integration version: `ECDICT 2026.09 (MIT)`

The application uses this data only for offline word lookup and to present a compact set of common Chinese meanings during wordbook import. Imported source-file translations are intentionally ignored.
