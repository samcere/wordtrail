# 学习工作台 0.16

词表管理中可直接删除词表。确认后会同时删除该词表的关联计划及进度；已生成的 PDF 和错题整理资料保留。建议先导出备份。

导入固定保留文件原顺序，不再提供乱序选项。背诵表与考试表使用各自独立的随机顺序；一旦生成，重复下载保持顺序和题号不变，答案表跟随考试表。

TXT、JSON、CSV、Excel 均支持完整英文词组（如 `look forward to`）。词组中的空格不会拆词，原翻译仍忽略；补充 357,824 条词组词典，按首字母分片并按需加载。未收录的词组完整保留并标注「词典暂未收录」，不会套用第一个单词的释义。TXT 每行一条，英文在前、中文在后；表格可用「单词 / 词组 / 短语 / word / phrase」列，JSON 支持条目数组及英文到释义的映射。

首页只有「背单词」和「错题整理」两个小按钮。点哪个才展开哪个工具，不展示每日单词、打卡、图表或宣传内容。

## 错题整理

迁入 `wrongbook-source-v14` 的题目存储、题类归档、LaTeX 排版、图片分题与区域截图、错因笔记、间隔复习和 PDF 导出。题目列表支持搜索、题类筛选、待复习筛选及勾选导出；未保存的编辑草稿可恢复。

本机助手、连接码、ChatGPT 登录和本地识别服务已移除。默认可以直接保存原图、录入正文，或粘贴外部 AI 按提示词生成的 `questions` JSON；多道题会拆分后逐题校对。

API 图片识别与错因分析为可选功能。用户自行填写服务、支持图片的模型名称和 API 密钥；密钥只保存在当前页面内存，不写入浏览器存储、不包含在备份里。调用可能产生 API 费用，且受服务模型能力、网络和浏览器跨域策略限制。没有 API 也可以使用其余所有整理和复习功能。图片与所选题目资料仅在用户主动确认后发给配置的服务。

右上角「备份」统一导出词表、学习计划、单词 PDF、错题、题类与复习记录。可分别导入旧词轨备份、原错题本 v2 备份，或整合工作台备份；单独导入一种备份不影响另一种数据。

原错题站点的浏览器数据不能跨域自动读取。请先在原站导出 JSON 备份，再在工作台导入；源码压缩包不包含用户题目。

这是可直接部署到 Cloudflare Pages、GitHub Pages 或其他静态网站托管平台的版本。

## 这个版本解决了什么

- 主界面精简为一个学习页，不再拆成四页。导入词表和设置每周数量一次完成，背词与测试原地切换。
- 管理、纸面测试和下载记录按需展开；PDF、Excel、涂卡识别组件仅在使用时加载。
- 不使用 `server.py`、Python 后端、数据库服务器或付费云资源。
- 词表、学习计划、测试进度和生成的 PDF 全部保存在当前浏览器的 IndexedDB。
- 内置 ECDICT 英汉词典：399,207 个单词及 357,824 个词组，分别按首字母拆成静态分片，按需加载。
- 所有文件均小于 Cloudflare Pages 的 25 MiB 单文件限制；最大词典分片约 4.3 MiB。
- 支持 TXT、JSON、CSV、XLS、XLSX 导入，只提取英文单词或词组，保留源顺序，忽略源文件已有翻译并用内置词典补全。
- 支持按每周期词数自动规划；第二周期起约 10% 为历史词复习。
- 支持在线周测、纸面周测、复测、S+ / S / A / B / C / D 评级。
- 背诵表、考试表和答案表每页最多 60 词，左右双栏、每栏最多 30 词；不足 60 词时自动均衡分栏。背诵表与答案表不显示音标，常用释义与单词同排。错题勾选卡独立成页，每页最多 300 题。
- 勾选卡包含页面核验二维码；浏览器用 OpenCV.js 和 jsQR 做透视矫正、页面匹配和涂点识别。
- PDF 在浏览器中生成，同时保存到页面底部「下载记录」并触发下载；中英文字体完整嵌入 PDF，不依赖设备字体。
- 支持完整备份/恢复，备份会包含词表、计划、进度和文档中心内的 PDF。
- 包含 PWA 缓存；首次联网打开后，已使用过的词典分片和识别组件会逐步缓存。

## Cloudflare Pages 部署

最省事的方式是新建一个干净的 GitHub 仓库，把本文件夹内的内容放在仓库根目录：

1. Cloudflare 控制台进入 **Workers & Pages**，创建 **Pages** 项目并连接 GitHub 仓库。
2. Framework preset 选择 **None**。
3. Build command 留空。
4. Build output directory 填 `.`。
5. 保存并部署。

不要把旧的 `dictionary/ecdict.csv` 放进这个仓库。部署需要的是本目录 `dictionary/a.json` 到 `z.json` 的分片。

## GitHub Pages 部署

1. 把本文件夹内容放在仓库根目录并推送到 `main`。
2. 仓库 Settings -> Pages。
3. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
4. 保存后等待 GitHub Pages 给出网址。

## 数据说明

不同设备和不同浏览器不会自动同步数据。换设备前在右上角「备份」下载完整备份，在新设备导入即可迁移。

不要用资源管理器直接双击 `index.html` 作为日常使用方式：浏览器的 `file://` 安全规则会阻止词典分片加载。部署后的 HTTPS 网站不需要你手动启动任何服务。

旧 PDF 不会被覆盖。更新后重新下载，系统按新模板生成新版本。更改计划名称后也会生成对应的新文档。

## 目录

- `index.html` / `interface.css` / `app.js`：网站界面、电脑与手机共用样式及交互逻辑。
- `static-service.js`：浏览器内的数据、计划、测试、PDF 和备份逻辑。
- `workbench.js`：两个工具入口、按需加载和统一备份。
- `wrongbook-store.js` / `wrongbook.js`：错题数据、录入、校对、复习和 PDF 排版。
- `wrongbook-ai.js` / `wrongbook-prompt.js`：可选 API 调用、识别结果校验及原 v14 转录规则。
- `omr.js`：纸面答题卡核验与识别。
- `dictionary/`：已分片的英汉词典。
- `vendor/`：Excel、二维码、OpenCV、PDF 生成组件及 PDF 内嵌字体。
- `manifest.webmanifest` / `sw.js`：安装与离线缓存。
- `_headers` / `.nojekyll`：Cloudflare Pages 与 GitHub Pages 配置。

第三方开源组件和数据的许可见 `THIRD-PARTY-NOTICES.md`。
