# 词轨 Wordtrail v0.10（本地可运行版）

这是一个可离线使用的本地单词学习工具。它会把你的词表、学习计划、考试结果与 PDF 文档保存于当前文件夹。

## 打开

若将 v0.10 文件夹移动到另一台电脑，先按其中的 `requirements.txt` 安装依赖；随后双击 `启动词轨.cmd` 即可启动服务并打开网页。

## 已实现

- 导入 TXT / JSON / CSV / XLS / XLSX 单词本；下载只含英文词的模板即可开始。
- 内置 ECDICT 离线英汉词典：导入时只提取英文单词，自动补充最多 3 个常用中文义；源文件中跟随的中文翻译、备注和其他字段不会覆盖词典释义。
- 导入前展示可勾选的识别预览、词典匹配状态、常用义与待补全词；未收录的英文词仍可导入，之后可补充释义。
- 选择任意数量的本周词条创建计划；没有周词量上限。
- 生成并下载 A4 背诵表、考试表与答案表；背诵表与考试表均按每页 30 个词排版，生成的 PDF 会先进入文档中心。
- 纸面错题卡每页容纳 150 题，采用 OMRChecker 的模板化识别：涂满左侧圆圈代表错题，四个牛眼定位标记会校正拍摄倾斜后再识别。每张卡都有页面核验二维码，上传时自动确认当前计划、考试表与页码；不匹配的卡会被拒绝导入。
- 同一份快照重复下载不会重复创建文档；词条变化后会形成新的修订版。

## 本地数据位置

- `data/wordtrail.json`：词表、计划、试卷与文档索引。
- `documents/`：实际生成的 PDF 文件。
- `dictionary/ecdict.csv`：随应用携带的 ECDICT 离线词典数据（MIT 许可）。许可证见 `dictionary/ECDICT-LICENSE.txt`，来源说明见 `dictionary/THIRD-PARTY-NOTICES.md`。
- `vendor/xlrd/`：随应用携带的旧版 `.xls` 读取组件。
- `vendor/OMRChecker/`：纸面勾选卡识别引擎及其许可文件；首次运行所需图像依赖已随本机环境配置。

这些数据仅存储在此设备。本初版不含账号、云同步或多人协作功能；首次打开时不会附带任何示例词表、计划或文档。
